# Made for Github Game Off Jam 2026

This game was originally envisoned as a halloween event for my SMP back in 2024. Having made virtually zero progress on it in the two years since, I've decided to work on this for the [Github Game Off Jam 2026](https://itch.io/jam/game-off-2026).

Currently, the only progress made is some tweaks to vanilla villagers and generic stuff like session management, commands, utils, etc, which together only make up a template or starter project base.
